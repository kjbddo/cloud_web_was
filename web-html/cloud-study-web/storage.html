스토리지 파일 업로드 실습

이 화면은 WAS가 application.properties의 스토리지 설정을 읽고 Azure Blob Storage와 Azure File Storage REST API를 호출하는지 확인합니다. 같은 이름으로 업로드하면 파일이 덮어쓰기됩니다.

SAS 토큰에는 Blob 컨테이너와 File Share에 대한 목록, 쓰기, 생성, 삭제 권한이 필요합니다.

Blob Storage

storage.account, storage.container, storage.sas를 사용합니다.

이름유형작업

File Storage

storage.file.share, storage.file.directory, storage.sas를 사용합니다.
