DB CRUD 실습

/config.html에서 저장한 db.endpoint, db.username, db.password를 이용해 WAS가 DB에 연결합니다. 이 화면은 DDL 예시의 cloud_assets 테이블을 기준으로 조회, 추가, 수정, 삭제를 수행합니다.

먼저 docs/sql/cloud-study-mysql-ddl.sql을 DB에서 실행하고, db.endpoint의 DB 이름을 cloud_study_app으로 맞추는 것을 권장합니다. MySQL은 WAR에 드라이버가 포함되어 있습니다. 다른 DB를 사용할 경우 해당 JDBC 드라이버를 Tomcat lib 또는 WAR 의존성에 추가하세요. 

아직 연결 확인을 하지 않았습니다.
